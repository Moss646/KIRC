# 05 — Multi-cohort external validation

Runs Cox models, KM curves, cross-cohort classifier concordance, 68/14/16/
31/9-gene validation, and produces the summary CSV + Word tables.

## Pipeline
cd scripts
python run_all.py # full pipeline, including DOCX
python run_all.py --skip-docx # skip Word tables
python run_all.py --only NAME # run a single script

text

Pipeline stages are defined in `scripts/run_all.py`:

- **PREP**: `make_mapping_jsons.py`
- **CORE**: `simple_cox_all_cohorts.py`, `prognostic_cox.py`,
  `external_validation_KM_pubsize.py`, `classifier_concordance.py`,
  `key14_biological.py`, `panel_G_CPTAC_protein.py`, `diagnostics.py`
- **EXTRA**: `key14_cross_cohort_v2.py`, `lipid16_cross_cohort_v2.py`,
  `lipid31_cross_cohort_v1.py`, `nonncc9_fao_cross_cohort_v1.py`,
  `external_validation_KM_score_combined_v3.py`, `driver_mut_fao_v1.py`
- **SUMMARY**: `verify_all_values.py`, `generate_summary_csv.py`
- **DOCX**: `build_table_docx.py`, `build_split_tables.py`, `build_Table3.py`

## Manual copy

`make_mapping_jsons.py` reads `data/balanced_genes.txt` directly. You must
copy it here manually; otherwise the script exits with a clear message.

```bash
# 68-gene panel (required)
cp ../06_FigureS1_gene_selection/data/consensus_cluster/balanced_genes.txt \
   data/balanced_genes.txt

# Classifier artifacts
cp ../01_Figure1_clustering/data/subtype_classifier.json data/classifier/
cp ../01_Figure1_clustering/data/subtype_assignment_balanced.csv data/classifier/

cp ../09_TCGA-KIRC_prep/data/tcga_kirc/KIRC_clinical_cleaned.csv data/classifier/
