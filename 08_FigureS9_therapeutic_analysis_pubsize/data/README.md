## Where to obtain the raw inputs

- **`kirc_expr_matched.csv`** — TCGA-KIRC log2(TPM+1) expression matrix,

&#x20; 14097 genes × 533 samples. Download from [TCGA GDC](https://portal.gdc.cancer.gov/)

&#x20; (project TCGA-KIRC, Transcriptome Profiling → Gene Expression Quantification),

&#x20; merge per-sample files and compute log2(TPM+1).

- **`subtype_assignment_balanced.csv`** — output of the NCC classifier

&#x20; (see the separate `Figure2_clustering` repository).

- **`oncoPredict_*.csv`** — produced by running oncoPredict (R package) on

&#x20; the expression matrix with GDSC2 drug response data. See Methods.

&#x20; - `oncoPredict_R_results.csv` (glmnet-based; only used to preserve the

&#x20;   original drug ordering)

&#x20; - `oncoPredict_calcPheno_results.csv` (official calcPhenotype; per-drug

&#x20;   summary with S1_mean, S2_mean, p, FDR)

&#x20; - `oncoPredict_calcPheno_ic50.csv` (official calcPhenotype; per-sample

&#x20;   IC50 matrix, 533 samples × 9 drugs)

## Required column formats

- `subtype_assignment_balanced.csv` — `Patient` (12-char TCGA ID),

&#x20; `Subtype` (`Subtype_1` or `Subtype_2`)

- `oncoPredict_calcPheno_results.csv` — `Drug`, `S1_mean`, `S2_mean`,

&#x20; `p`, `FDR`

- `oncoPredict_calcPheno_ic50.csv` — rows = samples, columns = 9 drugs

&#x20; (first 9 columns are used)
